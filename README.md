# CRUD de cafetería

Aplicación sencilla en JavaScript para administrar y consultar el menú de una
cafetería. Incluye operaciones para agregar, insertar, actualizar, eliminar,
buscar, filtrar y ordenar productos, además de generar códigos para los
elementos del menú.

## Ejecución


### En el navegador

Abre `index.html` en un navegador. El archivo carga `app.js`; para ver los
resultados, abre las herramientas de desarrollador del navegador y consulta la
consola.

## Métodos de array utilizados

- `push()` y `unshift()`: agregan productos al final y al inicio.
- `splice()`: inserta, actualiza o elimina productos en una posición.
- `findIndex()`: localiza un producto por nombre.
- `pop()` y `shift()`: eliminan el último y el primer producto.
- `find()`: busca el primer producto que coincide con un término.
- `filter()`: obtiene los productos que coinciden con una categoría.
- `sort()` y `reverse()`: ordenan el menú en forma ascendente o descendente.
- `slice()`: crea una copia del menú.
- `concat()`: combina el menú con los productos de temporada.
- `reduce()`: reúne los nombres de productos en una cadena.
- `map()`: genera códigos para los productos.
- `forEach()`: recorre y muestra los elementos del menú.
